Does it still work today?

A signal can be solid over the whole history and still have faded in recent years. Each rule by period: % of times the price was higher at the end of the horizon, against the average for that same period. ● = significant difference in that period (binomial test on non-overlapping cases, p < 0.05). With few cases per period, most differences do not reach significance even if they exist.

Measures

    {{rentFutura}}
  • Spearman correlation: uses the ranks of the values rather than their magnitude, so it is not affected by outliers or by non-linear relationships.
  • Zones and rules: % of times {{sujeto}} was higher at the end of the horizon, and average return, compared with the average over the same period.
  • Events (crossovers, first yield-curve inversion, first 20% drawdown…): each one is counted once. Only events at least one horizon apart are used in the statistical test.

Statistical tests

  • Circular block bootstrap with blocks the size of the horizon: it accounts for the overlap of long-horizon returns (two consecutive months share 119 of 120 months at 10 years). A textbook formula would make almost everything "significant".
  • Benjamini-Hochberg correction for multiple comparisons, separately for correlations, zones and events. With correlations and zones, 5% would come out significant by chance.
  • Conservative test: repeats the test counting only non-overlapping periods (a t-test with as many degrees of freedom as independent periods; for zones, an exact binomial test on separated observations). It addresses the critique by Boudoukh, Richardson and Whitelaw (2008) on "long-horizon predictability".
  • Levels: solid passes the multiple-comparison correction and the conservative test; hint only the first; the rest, no evidence.
  • Everything is reproducible: the bootstrap uses a fixed seed and the code is in src/, with automated tests in src/pruebas.test.mjs.
